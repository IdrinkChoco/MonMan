# MonMan

MonMan adalah aplikasi pribadi untuk membantu mencatat, mengelola, dan melacak keuangan sehari-hari.

## Tentang Aplikasi

Aplikasi ini dirancang sebagai pencatat keuangan pribadi yang menyimpan informasi pemasukan, pengeluaran, dan kondisi keuangan agar lebih mudah dipantau.

## Tujuan

- Melacak pemasukan dan pengeluaran pribadi
- Membantu memahami kebiasaan penggunaan uang
- Menyajikan ringkasan kondisi keuangan secara sederhana
